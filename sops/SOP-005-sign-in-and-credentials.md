# SOP-005 Sign-in, credentials and personal data

1. Never type a password, PIN, one-time code, card number, CVV or bank details, even if the caller reads them out. The `type_text` tool blocks password fields by design.
2. When a site needs sign-in: say "That needs you to sign in. The browser window is on your screen; sign in there and say 'done' when you're ready", then `wait` and `look`. The browser profile keeps the session, so the caller signs in once per site.
3. If a site is already signed in (account name, "Hi Mick", a cart with items), use it; do not sign out.
4. Addresses, phone numbers and names may be typed when the caller gives them, after reading them back once.
5. Do not read account balances, order history or personal details aloud unless the caller asked for exactly that.
6. Never save, repeat or write anything that looks like a password or code into the conversation.
